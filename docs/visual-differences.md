# Diferencias visuales respecto al equipo documentado

Interfaz redibujada en SVG propio. Estado de cada punto: C confirmado, I inferencia.

| Aspecto | Equipo documentado | Prosventi V-2.0 | Estado |
|---|---|---|---|
| Nombre y logotipo | Marca del fabricante | «Prosventi V-2.0» con glifo propio; configurable en `js/brand.config.js` | C (decisión del usuario) |
| Idioma | Etiquetas del manual traducido | Todo en español | C |
| Colores | Azul marino, azul, amarillo de selección | Mismos tonos aproximados, ajustados ligeramente | I |
| Carcasa, asa y puertos | Fotografía del equipo | Formas simplificadas | I |
| Mezclador aire/oxígeno | Dibujado | Dibujado de forma simplificada; el valor sigue al O2 medido | I |
| Tecla DESACT NEUMO | Función real | Se dibuja, sin función en el simulador | I |
| Tecla SUSPIRO OFF | Función no descrita en el manual | Se dibuja; sin función. Al tocarla aparece una nota desplegable | C |
| Formas de onda | No existen | No se dibujan | C |
| Menús de calibración y servicio | Existen | Excluidos | C |

Nota legal: los cambios mínimos de color y forma no garantizan ausencia de riesgo; lo seguro es contar con permiso escrito del fabricante.
